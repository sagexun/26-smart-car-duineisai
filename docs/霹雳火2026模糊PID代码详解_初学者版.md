## 第 0 章 先搞清楚这份文档在讲什么

这一整套代码最终只干一件事：**让车沿着赛道中线跑，该直走直走、该拐弯拐弯**。

它的完整链路是这样的（先有个印象，后面每段都会细讲）：

```
摄像头看到赛道 → 视觉算出偏差 image_bias（车偏离中线多少，±20）
   ↓
转向环（每10ms一次）：模糊PID 把偏差变成"左右轮速度差"  ★ 本文主角
   ↓
速度环（每2ms一次）：把左右轮实际速度追到目标速度（输出PWM）
   ↓
电机转动 → 编码器测量实际速度 → 反馈给速度环
```

**模糊 PID 负责的是中间那一步**：它不直接输出 PWM，它输出的是**左右轮目标速度差的比例**。这一章，我们就把它从输入到差速的每一步拆开。

## 第 1 章 大白话先懂三个词：PID、模糊、差速

### 1.1 PID 是什么（用"开车"打比方）

- **P（比例）**：看见偏了多少，就按比例打方向盘。偏 5cm 打一点，偏 20cm 打很多。**反应快慢**就看 P 大不大。但 P 太大，车会左右画龙（过头了又往回打）。
- **I（积分）**：记仇。如果一直有很小的偏差（比如 1cm 的静差）怎么打都消不掉，I 就慢慢累积力气，把它"磨"掉。**消除长期小误差**。
- **D（微分）**：预判刹车。看偏差是**在变大还是在变小**——正在快速变大的（要入弯了），就提前使劲；正在快速变小的（快回正了），就提前松手别冲过头。**抑制过冲和抖动**。

转向环用的是 **PD**（没有 I，因为转向不需要消除静差），速度环用的是 **PI**（没有 D，因为速度反馈有噪声，微分会放大噪声）。

### 1.2 模糊控制是什么（老师傅的经验表）

模糊控制不写精确公式，而是把**老师傅的经验**写成一张表：

> "偏差很大、而且还在快速变大（快撞进急弯了）→ 得用大 Kp 猛打方向"
> "偏差很小、基本没变化（直道）→ 用小 Kp 慢慢修，别抖"

这些"差不多"的规则（很大、中、小、零）就是**模糊语言**。电脑不能直接理解"很大"，所以要用**隶属度**把数字翻译成"有多大程度算很大"。这就是模糊控制。

### 1.3 差速转向是什么（为什么车能转弯）

这辆车左右各一个电机，各自独立驱动。**左右轮速度不一样，车就转弯**：

| 情况 | 左轮 | 右轮 | 结果 |
|---|---|---|---|
| 直行 | 速度 B | 速度 B | 走直线 |
| 左转 | 减速 | 保持/微加速 | 车头往左偏 |
| 右转 | 保持/微加速 | 减速 | 车头往右偏 |

所以"控制转向"本质 = **控制左右轮目标速度的差值**。模糊 PID 输出的"系数"，最终就是要变成这个差值。

## 第 2 章 全景：模糊PID在这一套代码里的位置

先看调用关系（从上往下）：

```
main.cpp: turn_callback()          ← 每 10ms 定时器触发一次
   │
   ├─ 决定偏差来源：正常循迹用 image_bias；绕行 YAW 用 IMU 角度误差
   ▼
driver/Motor.cpp: MotorDriver_TurnControlNew(bias)
   │
   ├─ Kp = Fuzzy_P(E, EC, 基础Kp)     ← 模糊 PID 出场：按工况调 Kp
   ├─ Kd = Fuzzy_D(E, EC, 基础Kd)     ← 按工况调 Kd
   ├─ pid_val = (Kp·E + Kd·EC) / 20   ← PD 算出一个"转向强度"
   └─ encoder_left_wish / encoder_right_wish  ← 差速！左右轮目标速度
   │
   ▼
速度环（2ms）：增量式 PI 把实际速度追到 encoder_left_wish / encoder_right_wish
   ▼
PWM → 电机
```

**一句话版本**：模糊 PID 在"转向环"内部，负责**动态调整 PD 的两个参数**；PD 再用调好的参数算出**差速比例**，最终变成左右轮目标速度。

## 第 3 章 模糊PID的两个输入：E 和 EC（白话）

看代码第一行接口：

```cpp
float Fuzzy_P(float E, float EC, float Steer_P);   // FuzzyPID.hpp
float Fuzzy_D(float E, float EC, float Steer_D);
```

两个输入：

- **E（Error，偏差）**：车偏离中线的程度。就是 `image_bias`，范围 **±20**。
  - E > 0：中线在车左边，需要左转；
  - E < 0：中线在车右边，需要右转；
  - E = 0：正对中线。
- **EC（Error Change，偏差的变化量）**：这一帧偏差比上一帧**变了多少**，即 `E - 上一帧的E`。
  - EC > 0：偏差在**变大**（车越来越偏，比如正在入弯）；
  - EC < 0：偏差在**变小**（车正在回正，比如出弯）；
  - EC ≈ 0：偏差基本没动（直道）。

在 `TurnControlNew` 里是这样取到 EC 的：

```cpp
static float last_error = 0.0f;              // 记住上一帧的偏差
float error = bias;                          // 这一帧的偏差 E
Kp = Fuzzy_P(error, (error - last_error), Kp);  // 第二个参数就是 EC
...
last_error = error;                          // 算完把这一帧存起来，下次用
```

> **白话**：E 回答"偏了多少"，EC 回答"正在偏得更厉害还是在回正"。有了这两个，控制器才能分清"直道 / 入弯 / 出弯"三种情况，分别对待。

## 第 4 章 论域、语言值和隶属度（白话）

### 4.1 语言值：把数字翻译成"人话"

代码把偏差分成了 7 个档（语言值）：

| 缩写 | 全称 | 白话含义 |
|---|---|---|
| NB | Negative Big | 负得很大（需要很用力地往右打方向） |
| NM | Negative Medium | 负得中等 |
| NS | Negative Small | 负得一点点 |
| ZO | Zero | 零（直道） |
| PS | Positive Small | 正得一点点（需要稍微往左打） |
| PM | Positive Medium | 正得中等 |
| PB | Positive Big | 正得很大（需要很用力地往左打） |

代码里用数字 0~6 代表它们（`fuzzy_idx_t`，见 `FuzzyPID.hpp`）。

### 4.2 论域：每个档的"地盘"边界

```cpp
// E 的 7 个边界（把 -16~16 切成 6 段，档位锚点在边界上）
static const float E_BOUNDARIES[7] = {-16.0f, -8.0f, -3.0f, 0.0f, 3.0f, 8.0f, 16.0f};
// EC 的 7 个边界
static const float EC_BOUNDARIES[7] = {-6.0f, -2.0f, -1.2f, 0.0f, 1.2f, 2.0f, 6.0f};
```

> **白话**：E 在 ±16 之间活动，EC 在 ±6 之间活动。注意边界不是均匀分布的——**零点附近挤得密（-3,0,3 / -1.2,0,1.2），远处稀疏**。为什么？直道时偏差经常在零点附近小幅晃动，零点附近分得细，控制器对"直道上的小偏差"就更敏感；远处理论上很少去，分粗一点没关系。

### 4.3 隶属度：这个数"像哪个档"到什么程度

经典思维：E=6 只能属于一个档。模糊思维：**E=6 同时"有点属于 PS、更属于 PM"**。隶属度 μ 就是 0~1 之间表示"像的程度"。

代码用**三角隶属函数**：每个档是一个三角形，**顶点（μ=1）在锚点上，落到相邻锚点（μ=0）**。计算就是简单的线性插值：

```cpp
mu_e[0] = (e_hi - E) / (e_hi - e_lo);   // 属于"低档"的程度（离低锚点越近越大）
mu_e[1] = 1.0f - mu_e[0];               // 属于"高档"的程度
```

E=6 落在区间 [3, 8] 之间（低档 PS、高档 PM）：
- μ_PS = (8−6)/(8−3) = **0.4**
- μ_PM = 1 − 0.4 = **0.6**

> **三个要记住的性质**：
> 1. 一个输入点最多只让**相邻两个档**非零；
> 2. 两个 μ **加起来恒等于 1**（所以后面加权平均不用再归一化）；
> 3. 恰在锚点上时 μ=1（只属于那一档）；超出论域时饱和（E≤-16 就一直算 NB）。

（配套《隶属度函数可视化.html》把这两张三角形图都画出来了，对着看。）

## 第 5 章 一步步读代码（核心函数）

### 5.1 第一步：把输入变成档位编号——`E_To_Index`

```cpp
static inline fuzzy_idx_t E_To_Index(float E) {
    if (E <= -16.0f) return 0;   // NB
    if (E <=  -8.0f) return 1;   // NM
    if (E <=  -3.0f) return 2;   // NS
    if (E <=   3.0f) return 3;   // ZO
    if (E <=   8.0f) return 4;   // PS
    if (E <=  16.0f) return 5;   // PM
    return 6;                    // PB
}
```

**逐行白话**：从上往下问"E 是不是比这个边界还小？"，是就返回对应的档位编号。比如 E=6：比 16 大？不是（6<16）；比 8 大？不是（6≤8）→ 返回 4（PS）。**最坏只要比较 3 次，O(1)，很快**。`EC_To_Index` 结构一模一样，只是边界换成 EC 的。

> 注意：`E<=3 返回 ZO` 意味着 E 从 -3 到 +3 都算"落在 ZO 区间"，但**具体偏向哪一边由后面的隶属度决定**（ZO 锚点是 0，所以 E=-1 离 ZO 近、离 NS 远）。

### 5.2 第二步：查规则表——`RULE_P` / `RULE_D`

这是模糊 PID 的"大脑"——两张 7×7 表，记录了"不同情况下该把增益放大还是缩小"的经验。

**P 规则表**（行=E 的档，列=EC 的档，格子=系数下标 0~6）：

```
       EC:  NB   NM   NS   ZO   PS   PM   PB
 E: NB      6    5    4    3    2    1    0
    NM      5    4    3    2    1    0    1
    NS      4    3    2    1    0    1    2
    ZO      3    2    1    0    1    2    3
    PS      2    1    0    1    2    3    4
    PM      1    0    1    2    3    4    5
    PB      0    1    2    3    4    5    6
```

**怎么读**（白话）：左上角 (NB,NB) = 6，意思是"偏差负很大、还在往负方向快速变大（在向右的急弯里越偏越深）→ P 放大到最大 1.30 倍，猛打"。右下角 (PB,PB) 同理。而右上角 (NB,PB) = 0："偏差负很大、但正在快速回正（出弯）→ P 压到最小 0.90 倍，别冲过头"。中间 (ZO,ZO)=0：直道，P 收小防抖。

**D 规则表**（和 P 互补）：

```
       EC:  NB   NM   NS   ZO   PS   PM   PB
 E: NB      0    1    2    3    4    5    6
    NM      1    2    3    4    5    6    5
    NS      2    3    4    5    6    5    4
    ZO      3    4    5    6    5    4    3
    PS      4    5    6    5    4    3    2
    PM      5    6    5    4    3    2    1
    PB      6    5    4    3    2    1    0
```

**怎么读**：中心 (ZO,ZO)=6 → 直道 D 放大到最大 1.35 倍，阻尼最足、压抖动；两个角落 (NB,NB)/(PB,PB)=0 → 入急弯 D 收到最小 0.85 倍，放开阻尼让它敢打。

> **一句话记法**：**P 在"要用力"时放大（入弯），D 在"要稳住"时放大（直道/出弯）**。
> 格子里的数字不是系数本身，是**系数表的下标**（见 5.4），0~6 分别对应 0.90~1.30（P）或 0.85~1.35（D）。

### 5.3 第三步：核心函数 `Fuzzy_Adjust` 逐行

这就是"动态调整"的全部秘密，一共 6 小步。代码（`FuzzyPID.cpp`）：

```cpp
static float Fuzzy_Adjust(float E, float EC, float base,
                          const int8_t rule[7][7],
                          const float uff_pct[7])
{
    // ── 第 1 步：输入限幅 ─────────────────────────────
    E  = CLAMP(E,  -16.0f, 16.0f);
    EC = CLAMP(EC, -6.0f, 6.0f);
    // 白话：E 最大按 ±16 算，EC 最大按 ±6 算，超出就"卡"在边界，
    // 防止后面数组下标越界，也防止极端数据把增益算爆。

    // ── 第 2 步：把 E、EC 变成档位编号 ─────────────────
    fuzzy_idx_t e_idx  = E_To_Index(E);     // 0~6
    fuzzy_idx_t ec_idx = EC_To_Index(EC);   // 0~6

    // ── 第 3 步：找"和这个点最接近的 4 条规则" ──────────
    int8_t Un[4];
    if (e_idx < 6) {
        Un[0] = rule[e_idx][ec_idx];        // (E低档, EC低档)
        Un[1] = rule[e_idx + 1][ec_idx];    // (E高档, EC低档)
    } else {
        Un[0] = rule[6][ec_idx];            // E 已经是最大档，没有"高档"了，
        Un[1] = rule[6][ec_idx];            // 就重复自己（防止数组越界）
    }
    if (ec_idx < 6) {
        int e_next = (e_idx < 6) ? e_idx + 1 : 6;
        Un[2] = rule[e_idx][ec_idx + 1];    // (E低档, EC高档)
        Un[3] = rule[e_next][ec_idx + 1];   // (E高档, EC高档)
    } else { ... 同理，EC 到最大档就重复自己 ... }

    // 白话：因为每个输入点只落在两个相邻档之间，
    // 所以最多"4 个角的规则"参与（E 两档 × EC 两档 = 4）。

    // ── 第 4 步：算隶属度（线性插值）───────────────────
    float mu_e[2], mu_ec[2];
    if (e_idx < 6) {
        float e_lo = E_BOUNDARIES[e_idx];
        float e_hi = E_BOUNDARIES[e_idx + 1];
        mu_e[0] = (e_hi - E) / (e_hi - e_lo);   // 属于低档的程度
        mu_e[0] = CLAMP(mu_e[0], 0.0f, 1.0f);   // 防浮点误差越界
        mu_e[1] = 1.0f - mu_e[0];               // 属于高档的程度
    } else {
        mu_e[0] = 1.0f; mu_e[1] = 0.0f;         // 饱和：只属于最大档
    }
    // EC 同理，用 EC_BOUNDARIES
    // 白话：E=6 → mu_e = {0.4, 0.6}，表示"40% 像 PS，60% 像 PM"。

    // ── 第 5 步：取小运算（AND）——算每条规则的"激活强度"──
    float UF[4];
    UF[0] = (mu_e[0] < mu_ec[0]) ? mu_e[0] : mu_ec[0];  // min
    UF[1] = (mu_e[1] < mu_ec[0]) ? mu_e[1] : mu_ec[0];
    UF[2] = (mu_e[0] < mu_ec[1]) ? mu_e[0] : mu_ec[1];
    UF[3] = (mu_e[1] < mu_ec[1]) ? mu_e[1] : mu_ec[1];
    // 白话：一条规则说"如果 E 是 PS 且 EC 是 PS"，那它成立的程度
    // 取两者小的那个（一票否决：两头都满足才算数）。

    // ── 第 6 步：加权平均解模糊 ───────────────────────
    float weighted_sum = 0.0f, sum_weights = 0.0f;
    for (int i = 0; i < 4; i++) {
        if (UF[i] > 0.0f) {
            float output = base * uff_pct[Un[i]];   // 每条规则的"建议输出"
            weighted_sum += UF[i] * output;         // 按激活强度加权
            sum_weights  += UF[i];
        }
    }
    return (sum_weights > 0.0f) ? (weighted_sum / sum_weights) : base;
    // 白话：4 条规则各自建议一个系数（base × 系数表[规则值]），
    // 按激活强度加权平均，得到"平滑连续"的最终系数。
    // 激活强度全为 0（理论上不会）就退回基础值 base。
}
```

**这就是"动态调整"的数学本质**：增益不是几个固定档位跳来跳去，而是 E、EC 的**连续函数**——E、EC 一变，系数平滑地跟着变。

### 5.4 第四步：公共接口 `Fuzzy_P` / `Fuzzy_D` + 系数表

```cpp
float Fuzzy_P(float E, float EC, float Steer_P) {
    static const float PCT[7] = {
        0.90f, 0.95f, 1.00f, 1.03f, 1.10f, 1.20f, 1.30f   // P 的系数表
    };
    return Fuzzy_Adjust(E, EC, Steer_P, RULE_P, PCT);
}

float Fuzzy_D(float E, float EC, float Steer_D) {
    static const float PCT[7] = {
        0.85f, 0.92f, 0.98f, 1.03f, 1.10f, 1.18f, 1.35f   // D 的系数表
    };
    return Fuzzy_Adjust(E, EC, Steer_D, RULE_D, PCT);
}
```

**白话**：规则表里 0~6 这个数字 → 查 PCT 表 → 得到"放大倍数"。
- 规则值 0 → ×0.90（P）/ ×0.85（D）：收缩增益；
- 规则值 3 → ×1.03：基本不动（≈基础值）；
- 规则值 6 → ×1.30（P）/ ×1.35（D）：放大增益。

所以 `Fuzzy_P(6, 2, 1.52)` 返回 `1.52 × 1.07 ≈ 1.63`。**这就是"基础 Kp 1.52 被动态调成 1.63"的完整过程**。

> `USE_CAR_108` 宏（在 `Typedef.hpp`）切换另一套系数表（108 开发板验证版），原理一样，只是数值不同——那是为另一辆车调的。

## 第 6 章 ★ 模糊PID怎么控制差速（重点）

模糊 PID 算出了调好的 Kp/Kd，但**真正让车转弯的是差速**。这一步在 `driver/Motor.cpp` 的 `MotorDriver_TurnControlNew` 里完成。整段代码：

```cpp
void MotorDriver_TurnControlNew(float bias) {
    static float last_error = 0.0f;            // 记住上一帧偏差

    float error = bias;                        // ① 这一帧偏差 E
    float Kp = turn_pid_new.Kp;                // ② 取出基础增益：{Kp=1.52, Kd=10.4}
    float Kd = turn_pid_new.Kd;

    // ③ 模糊 PID 动态调参（上一章的内容）
    Kp = Fuzzy_P(error, (error - last_error), Kp);   // Kp = 1.52 × 系数
    Kd = Fuzzy_D(error, (error - last_error), Kd);   // Kd = 10.4 × 系数

    fuzzyp = Kp;                               // ④ 存到全局量，方便上位机看波形
    fuzzyd = Kd;
    ec = error - last_error;
    ec = Limit(ec, -3.0f, 3.0f);               // ⑤ EC 再限幅 ±3（防偏差跳变把 D 项炸大）

    // ⑥ PD 合成：先乘后加再除 20 —— 这就是"转向强度" pid_val
    float pid_val = (Kp * error + Kd * ec) / 20.0f;
    last_error = error;

    // ⑦ 差速分配：pid_val > 0 → 左转；< 0 → 右转
    if (pid_val > 0.0f) {
        // 需要左转：左轮（内轮）大减速，右轮（外轮）小加速
        encoder_left_wish  = (int16_t)((1.0f - pid_val * 0.95f) * base_speed);
        encoder_right_wish = (int16_t)((1.0f + pid_val * 0.1f) * base_speed);
        if (encoder_left_wish < 0) encoder_left_wish = 0;   // 内轮最低到 0，不许反转
    } else {
        // 需要右转：右轮（内轮）大减速，左轮（外轮）小加速（对称）
        float radian = -pid_val;
        encoder_right_wish = (int16_t)((1.0f - radian * 0.95f) * base_speed);
        encoder_left_wish  = (int16_t)((1.0f + radian * 0.1f) * base_speed);
        if (encoder_right_wish < 0) encoder_right_wish = 0;
    }
}
```

### 6.1 `pid_val` 到底是什么（白话）

`pid_val = (Kp·E + Kd·EC) / 20` 是一个**没有量纲的"转向强度"**：
- 它越大，说明偏差越严重（或偏差长得越快）→ 需要转得越狠；
- 除 20 是为了把它缩到"差速比例"的量级（E 最大 ±20，Kp~2，Kd~14，EC±3，所以 pid_val 大约在 ±4 以内）。

> 如果你把视觉队友的偏差量纲改了（比如改成 ±10），这个 20 必须跟着改，否则差速会整体放大或缩小。

### 6.2 为什么内轮减 0.95、外轮加 0.10（白话）

转弯不需要左右轮对称加减——工程上讲究"**减速为主、加速为辅**"：

- **内侧轮乘 (1 − pid_val×0.95)**：减得很猛。pid_val=1 时内轮几乎停（0.05×B），pid_val≈1.5 时内轮直接钳到 0。转弯最有效的动作就是"让内侧轮慢下来"；
- **外侧轮只乘 (1 + pid_val×0.10)**：加一点点。幅度小是为了**保住出弯速度**、防止外侧轮打滑甩尾。

对比一下就知道为什么不对称：如果 0.5/0.5 对称加减，同样的 pid_val 会损失更多速度，而且内外轮同时大改，车容易横甩。0.95/0.10 是老车（2025 TC264 例程的 xishu_down=0.9 / xishu_up=0.15）验证过的经验值，2026 把内侧减得更狠。

### 6.3 为什么内轮要"钳到 0"（白话）

大偏差时 pid_val 可能 >1，比如 pid_val=1.53：`(1 − 1.53×0.95) = −0.45`，内轮目标变成**负数**（反转）。正常循迹时内轮反转会让车原地打转、姿态乱掉。所以 `if (encoder_left_wish < 0) encoder_left_wish = 0;` 把内轮目标**最低钳到 0**（停转，不是反转）。
（只有绕行 YAW 阶段才允许反转——那个阶段有专门开关 `g_yaw_active`，属于绕行的特殊处理。）

### 6.4 三个例子，把差速完整算一遍

设基础 `Kp=1.52, Kd=10.4`，基础速度 `base_speed = B`。

**例 1：直道（E=0, EC=0）**

| 步骤 | 计算 | 结果 |
|---|---|---|
| 模糊系数 | P×0.90，D×1.35（E=0 恰在 ZO 锚点，μ=1） | Kp=1.37，Kd=14.04 |
| PD 合成 | pid_val = (1.37×0 + 14.04×0)/20 | **0** |
| 差速 | else 分支，radian=0 | L = B，R = B |

→ **左右轮一样快，直行。** 虽然 Kd 被放得很大，但 E=0、EC=0 时 D 项没用武之地。

**例 2：中等偏差且正在变大（E=6, EC=2）**

| 步骤 | 计算 | 结果 |
|---|---|---|
| 模糊系数 | P×1.07，D×1.00（上一章算过） | Kp=1.63，Kd=10.4 |
| PD 合成 | pid_val = (1.63×6 + 10.4×2)/20 = (9.76+20.8)/20 | **1.53** |
| 差速 | 左转分支 | L = (1−1.53×0.95)B = −0.45B → **钳到 0**；R = (1+1.53×0.10)B = **1.15B** |

→ **左轮停转、右轮提速 15%**，车头急往左拐。这正是"偏差中等但还在增大 → 提前猛打"的体现。

**例 3：急弯入弯（E=14, EC=5）**

| 步骤 | 计算 | 结果 |
|---|---|---|
| 模糊系数 | P×1.23，D×0.90（入弯：P 放大、D 放开） | Kp=1.87，Kd=9.31 |
| EC 限幅 | ec = Limit(5, ±3) = 3 | |
| PD 合成 | pid_val = (1.87×14 + 9.31×3)/20 = (26.2+27.9)/20 | **2.71** |
| 差速 | 左转分支 | L → **0**；R = (1+2.71×0.10)B = **1.27B** |

→ 极限打角：左轮停、右轮 +27%。偏差越大 pid_val 越大，转弯越狠——**这套逻辑自动完成"偏差越大打得越猛"**。

### 6.5 差速目标接下来去哪（和速度环交接）

`encoder_left_wish / encoder_right_wish` 是"目标速度"（编码器计数/2ms），**不是 PWM**。速度环（每 2ms，增量式 PI）拿"目标 vs 实际"算 PWM：

```cpp
// driver/Motor.cpp 的 2ms 回调里
new_pwm_left  = MotorDriver_LeftPidControl(encoder_left,  encoder_left_wish);
new_pwm_right = MotorDriver_RightPidControl(encoder_right, encoder_right_wish);
MotorDriver_SetLeftSpeed(new_pwm_left);   // 真正输出 PWM 到电机
MotorDriver_SetRightSpeed(new_pwm_right);
```

**分工一句话**：转向环（10ms，模糊PD）负责**说"该往哪转、转多狠"**（用差速目标表达）；速度环（2ms，PI）负责**执行**（让实际速度跟上目标）。外环慢、内环快，这是标准双层控制。

## 第 7 章 代码里的"细节彩蛋"（每个为什么）

| 代码细节 | 白话解释 |
|---|---|
| `CLAMP(E, ±16)`、`CLAMP(EC, ±6)` | 防越界、防极端值，输入再离谱也不会算出非法结果 |
| `e_idx < 6` 的分支 | E 已经是最大档（6=PB）时没有"高档"可查，重复自己防止数组越界（`rule[7]` 只到 6） |
| 隶属度算完再 `CLAMP(0,1)` | 浮点数除法可能有 0.9999999 之类的误差，钳一下保证 μ 在 [0,1] |
| `UF = min(μe, μec)` | "且"运算：规则两头都满足才算成立，强度取小的一头 |
| 加权平均只累加 `UF>0` | 激活强度为 0 的规则不影响结果，省运算 |
| `sum_weights=0` 时返回 base | 防御：万一没激活任何规则（理论不可能），退回基础值不崩 |
| `pid_val/20` | 把 PD 输出缩到差速比例量级，和 image_bias 的 ±20 量纲配套 |
| 内轮 0.95 / 外轮 0.10 | 减速为主、加速为辅：保速度、防甩尾 |
| 内轮钳到 0 | 防止正常循迹时内轮反转导致原地打转 |
| `ec` 再限 ±3 | 偏差跳变（如丢线、切元素）时，D 项不会瞬间爆掉 |
| `fuzzyp / fuzzyd` 全局量 | 调试用，上位机示波器可以直接看模糊输出 |

## 第 8 章 初学者最容易踩的坑

1. **image_bias 符号反了**：车往左偏时视觉给正还是负？必须先实车确认。符号反了，模糊规则表"入弯放大 P"就变成"入弯缩小 P"，表现是弯道越打越没反应；
2. **先调速度环再调转向环**：内环不跟手，外环调得再好也白搭；
3. **改偏差量纲必须改 /20**：视觉队友把 image_bias 改成 ±10，20 不改，差速整体变弱；
4. **不要一上来就动规则表**：调参数优先改 `turn_pid_new.Kp/Kd` 基础值和 `PCT[]` 系数表，7×7 规则表是"结构"，动了等于重新设计；
5. **内轮钳 0 是循迹的护身符**：别为了"转得更快"把钳位去掉，除非你在做绕行 YAW；
6. **`fuzzyp/fuzzyd` 是调试的眼睛**：调参时开着上位机看这两条曲线，直道应该接近基础值、入弯应该明显抬起来，波形不正常先查偏差符号。

#define FUZZYPID_HPP_
#include <stdint.h>

#ifdef __cplusplus
extern "C" {
#endif

```cpp
// FuzzyPID.cpp（核心）
static const float E_BOUNDARIES[7]  = {-16.0f, -8.0f, -3.0f, 0.0f, 3.0f, 8.0f, 16.0f};
static const float EC_BOUNDARIES[7] = {-6.0f, -2.0f, -1.2f, 0.0f, 1.2f, 2.0f, 6.0f};

static const int8_t RULE_P[7][7] = {
    {6,5,4,3,2,1,0},  // E: NB   ← 行是 E 的档，列是 EC 的档
    {5,4,3,2,1,0,1},  // E: NM
    {4,3,2,1,0,1,2},  // E: NS
    {3,2,1,0,1,2,3},  // E: ZO
    {2,1,0,1,2,3,4},  // E: PS
    {1,0,1,2,3,4,5},  // E: PM
    {0,1,2,3,4,5,6}   // E: PB
};
static const int8_t RULE_D[7][7] = {
    {0,1,2,3,4,5,6},
    {1,2,3,4,5,6,5},
    {2,3,4,5,6,5,4},
    {3,4,5,6,5,4,3},
    {4,5,6,5,4,3,2},
    {5,6,5,4,3,2,1},
    {6,5,4,3,2,1,0}
};

#define CLAMP(x, min, max)  ((x) < (min) ? (min) : ((x) > (max) ? (max) : (x)))

static inline fuzzy_idx_t E_To_Index(float E) {
    if (E <= -16.0f) return 0;
    if (E <=  -8.0f) return 1;
    if (E <=  -3.0f) return 2;
    if (E <=   3.0f) return 3;
    if (E <=   8.0f) return 4;
    if (E <=  16.0f) return 5;
    return 6;
}
static inline fuzzy_idx_t EC_To_Index(float EC) {
    if (EC <= -6.0f) return 0;
    if (EC <= -2.0f) return 1;
    if (EC <= -1.2f) return 2;
    if (EC <=  1.2f) return 3;
    if (EC <=  2.0f) return 4;
    if (EC <=  6.0f) return 5;
    return 6;
}

static float Fuzzy_Adjust(float E, float EC, float base,
                          const int8_t rule[7][7], const float uff_pct[7])
{
    E  = CLAMP(E,  -16.0f, 16.0f);          // 1. 限幅
    EC = CLAMP(EC, -6.0f, 6.0f);

    fuzzy_idx_t e_idx  = E_To_Index(E);     // 2. 档位编号
    fuzzy_idx_t ec_idx = EC_To_Index(EC);

    int8_t Un[4];                           // 3. 4 条相邻规则（防越界重复自己）
    if (e_idx < 6) {
        Un[0] = rule[e_idx][ec_idx];
        Un[1] = rule[e_idx + 1][ec_idx];
    } else {
        Un[0] = rule[6][ec_idx];
        Un[1] = rule[6][ec_idx];
    }
    if (ec_idx < 6) {
        int e_next = (e_idx < 6) ? e_idx + 1 : 6;
        Un[2] = rule[e_idx][ec_idx + 1];
        Un[3] = rule[e_next][ec_idx + 1];
    } else {
        int e_next = (e_idx < 6) ? e_idx + 1 : 6;
        Un[2] = rule[e_idx][6];
        Un[3] = rule[e_next][6];
    }

    float mu_e[2], mu_ec[2];                // 4. 隶属度（线性插值，和为 1）
    if (e_idx < 6) {
        float e_lo = E_BOUNDARIES[e_idx];
        float e_hi = E_BOUNDARIES[e_idx + 1];
        mu_e[0] = CLAMP((e_hi - E) / (e_hi - e_lo), 0.0f, 1.0f);
        mu_e[1] = 1.0f - mu_e[0];
    } else {
        mu_e[0] = 1.0f; mu_e[1] = 0.0f;
    }
    if (ec_idx < 6) {
        float ec_lo = EC_BOUNDARIES[ec_idx];
        float ec_hi = EC_BOUNDARIES[ec_idx + 1];
        mu_ec[0] = CLAMP((ec_hi - EC) / (ec_hi - ec_lo), 0.0f, 1.0f);
        mu_ec[1] = 1.0f - mu_ec[0];
    } else {
        mu_ec[0] = 1.0f; mu_ec[1] = 0.0f;
    }

    float UF[4];                            // 5. 取小（AND）＝激活强度
    UF[0] = (mu_e[0] < mu_ec[0]) ? mu_e[0] : mu_ec[0];
    UF[1] = (mu_e[1] < mu_ec[0]) ? mu_e[1] : mu_ec[0];
    UF[2] = (mu_e[0] < mu_ec[1]) ? mu_e[0] : mu_ec[1];
    UF[3] = (mu_e[1] < mu_ec[1]) ? mu_e[1] : mu_ec[1];

    float weighted_sum = 0.0f, sum_weights = 0.0f;
    for (int i = 0; i < 4; i++) {           // 6. 加权平均解模糊
        if (UF[i] > 0.0f) {
            float output = base * uff_pct[Un[i]];
            weighted_sum += UF[i] * output;
            sum_weights  += UF[i];
        }
    }
    return (sum_weights > 0.0f) ? (weighted_sum / sum_weights) : base;
}

float Fuzzy_P(float E, float EC, float Steer_P) {
    static const float PCT[7] = {0.90f, 0.95f, 1.00f, 1.03f, 1.10f, 1.20f, 1.30f};
    return Fuzzy_Adjust(E, EC, Steer_P, RULE_P, PCT);
}

float Fuzzy_D(float E, float EC, float Steer_D) {
    static const float PCT[7] = {0.85f, 0.92f, 0.98f, 1.03f, 1.10f, 1.18f, 1.35f};
    return Fuzzy_Adjust(E, EC, Steer_D, RULE_D, PCT);
}
```

### 9.2 转向环 + 差速（TurnControlNew，学习注释版）

```cpp
void MotorDriver_TurnControlNew(float bias) {
    static float last_error = 0.0f;
    float error = bias;                              // E
    float Kp = turn_pid_new.Kp;                      // 基础 1.52
    float Kd = turn_pid_new.Kd;                      // 基础 10.4
    Kp = Fuzzy_P(error, (error - last_error), Kp);   // 模糊调 Kp
    Kd = Fuzzy_D(error, (error - last_error), Kd);   // 模糊调 Kd
    fuzzyp = Kp;
    fuzzyd = Kd;
    ec = error - last_error;
    ec = Limit(ec, -3.0f, 3.0f);                     // EC 限 ±3
    float pid_val = (Kp * error + Kd * ec) / 20.0f;  // 转向强度
    last_error = error;
    if (pid_val > 0.0f) {                            // 左转
        encoder_left_wish  = (int16_t)((1.0f - pid_val * 0.95f) * base_speed);
        encoder_right_wish = (int16_t)((1.0f + pid_val * 0.1f) * base_speed);
        if (encoder_left_wish < 0) encoder_left_wish = 0;
    } else {                                         // 右转
        float radian = -pid_val;
        encoder_right_wish = (int16_t)((1.0f - radian * 0.95f) * base_speed);
        encoder_left_wish  = (int16_t)((1.0f + radian * 0.1f) * base_speed);
        if (encoder_right_wish < 0) encoder_right_wish = 0;
    }
}

   │  EC = E - 上一帧E
   ▼
Fuzzy_P / Fuzzy_D ──► Kp、Kd（基础值 × 0.85~1.35 的系数）
   │

   │
   ▼
pid_val>0 → 左轮 (1−0.95·pid_val)·B，右轮 (1+0.10·pid_val)·B，内轮钳≥0
pid_val<0 → 右轮 (1−0.95·|pid_val|)·B，左轮 (1+0.10·|pid_val|)·B，内轮钳≥0
   │
   ▼
encoder_left_wish / encoder_right_wish（目标速度）
   │
   ▼
速度环 2ms：增量式 PI → PWM → 电机 → 编码器反馈
```
