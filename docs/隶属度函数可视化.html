隶属度函数：输入值如何变成"属于某个语言值的程度"（示意）
7 个语言值 = 7 个三角隶属函数，锚点在论域边界上。任一输入点只与相邻两个三角形相交，两个隶属度之和恒为 1。
E 论域（偏差，±16）：E=6 → μ_PS=0.4，μ_PM=0.6
EC 论域（偏差变化率，±6）：EC=2 → μ_PM=1.0（恰在锚点，EC 不再参与插值）
完整工作示例（E=6, EC=2）—— 隶属度 → 规则激活强度 → 增益系数
① E=6 落在区间 [3, 8]：μ_PS = (8-6)/(8-3) = 0.4，μ_PM = 1-0.4 = 0.6；
② EC=2 恰在锚点 2：μ_PS = 0，μ_PM = 1.0（只属于 PM）；
③ E×EC 配对激活 4 条规则，激活强度取小：UF = {min(0.4,0), min(0.6,0), min(0.4,1), min(0.6,1)} = {0, 0, 0.4, 0.6}；
④ 加权平均（只算非零）：P 系数 = (0.4×1.03 + 0.6×1.10)/1.0 = 1.07，D 系数 = (0.4×1.03 + 0.6×0.98)/1.0 = 1.00。
要点：EC 恰在锚点时只贡献 1 条语言值，插值完全由 E 提供——这就是"相邻区间线性插值"的实际效果。
几何与数值按 FuzzyPID.cpp 的 E_BOUNDARIES / EC_BOUNDARIES 与 Fuzzy_Adjust 公式绘制，示例数据标注明确。示意结构，非精确测量。
