## 1. 整体控制架构（先看数据流）

这是一辆**四轮差速转向车**（无舵机输出，转弯靠左右轮差速），主控为英飞凌 TC264 双核 MCU。控制任务分成两层：



| 核 / 中断              | 周期   | 任务                                             | 所在文件                            |
| ------------------- | ---- | ---------------------------------------------- | ------------------------------- |
| CPU1 主循环            | 图像帧  | 图像处理 `Image_Process()`、速度决策 `Speed_Decision()` | `user/cpu1_main.c`              |
| CPU0 PIT：CCU60\_CH0 | 2 ms | 置标志位 → 主循环里执行 `Motor_control()`（编码器测速 + 电机 PI） | `user/isr.c`、`user/cpu0_main.c` |
| CPU0 PIT：CCU60\_CH1 | 8 ms | 转向环 `turn_pid()`（图像偏差 → 差速目标速度）                | `user/isr.c`                    |
| CPU0 PIT：CCU61\_CH0 | 4 ms | 出界保护标志                                         | `user/isr.c`                    |

**控制链路（重点看这条链）：**



```
摄像头 → 图像处理(CPU1) → 中线偏差 ImageStatus.Det\\\_True

\&#x20;                                       │

\&#x20;                        8ms 转向环 turn\\\_pid（模糊 PD）   ← 外环：决定差速

\&#x20;                                       │

\&#x20;                             ENCO\\\_Wish\\\_L / ENCO\\\_Wish\\\_R  ← 目标速度

\&#x20;                                       │

\&#x20;                        2ms 电机环 Motor\\\_control（增量式 PI） ← 内环：跟踪速度

\&#x20;                                       │

\&#x20;                            set\\\_left\\\_speed / set\\\_right\\\_speed → PWM

\&#x20;                                       │

\&#x20;                            编码器计数（二阶滞后滤波） → 实际速度（反馈）

\&#x20;                                       └──────── 闭环 ────────┘
```

**核心结论：这个例程是 "内环速度 PI + 外环转向差速" 的两层结构。调电机 PID，调的是内环速度环（**`Motor_Left_PID`**&#x20;/&#x20;**`Motor_Right_PID`**）。**

## 2. 电机速度环：增量式 PI（核心代码）

### 2.1 代码位置



* 实现：`code/pid.c` → `motorL_pid()` / `motorR_pid()`

* 参数结构体：`code/pid.h` → `pid_param_t`

* 参数初值：`code/control.c` → `PID_Init()`

### 2.2 核心代码（左轮，右轮完全对称）



```
// pid.h —— PID 参数结构体

typedef struct

{

\&#x20; float Kp;   // 比例系数

\&#x20; float Ki;   // 积分系数

\&#x20; float Kd;   // 微分系数

}pid\\\_param\\\_t;

// pid.c —— 左电机速度环：增量式 PI

float I\\\_out\\\_L = 0;

int16 motorL\\\_pid(pid\\\_param\\\_t motorL\\\_pid, int16 enco\\\_true, int16 enco\\\_wish)  // 增量式PI

{

\&#x20;   static int16 error = 0;       // 当前误差

\&#x20;   static int16 last\\\_error = 0;  // 上次误差

\&#x20;   static int16 pwm\\\_L = 0;       // PWM 输出（累加量，static 保持）

\&#x20;   error = enco\\\_wish - enco\\\_true;              // 目标 - 实际

\&#x20;   I\\\_out\\\_L = motorL\\\_pid.Ki \\\* error;            // 积分项（增量式里的 I 项）

\&#x20;   // ★ I 项限幅：单次积分增量不能超过 Ki\\\*65，防止积分饱和

\&#x20;   if(I\\\_out\\\_L >  motorL\\\_pid.Ki\\\*65) I\\\_out\\\_L =  motorL\\\_pid.Ki\\\*65;

\&#x20;   else if(I\\\_out\\\_L < -motorL\\\_pid.Ki\\\*65) I\\\_out\\\_L = -motorL\\\_pid.Ki\\\*65;

\&#x20;   // ★ 增量式 PI 核心公式：ΔPWM = Kp\\\*(e - e\\\_last) + Ki\\\*e

\&#x20;   pwm\\\_L += motorL\\\_pid.Kp \\\* (error - last\\\_error) + I\\\_out\\\_L;

\&#x20;   // ★ 输出限幅 ±10000

\&#x20;   if(pwm\\\_L > 10000)      pwm\\\_L = 10000;

\&#x20;   else if(pwm\\\_L <= -10000) pwm\\\_L = -10000;

\&#x20;   last\\\_error = error;

\&#x20;   return pwm\\\_L;

}
```

### 2.3 公式与原理

这是标准的**增量式 PI**（也叫 "速度式 PID"）：



```
ΔPWM = Kp × (e(k) − e(k−1)) + Ki × e(k)

PWM(k) = PWM(k−1) + ΔPWM
```

与位置式 PID 相比，例程选增量式的理由：



1. **输出是 "变化量叠加"**：每次只加一个 ΔPWM，天然平滑，不会像位置式那样一次性输出大值；

2. **天然抗积分饱和**（配合 I 项限幅）：就算误差一直很大，单步增量也封顶，恢复时能快速收敛；

3. **对静态工作点不敏感**：输出是相对上次的增量，直道 / 弯道切换目标速度时不会跳变。

### 2.4 三个关键设计点（作者思路）



| 设计点       | 代码                                         | 作用                                            |
| --------- | ------------------------------------------ | --------------------------------------------- |
| 增量式       | `pwm_L += Kp*(error-last_error) + I_out_L` | 平滑、抗饱和                                        |
| **I 项限幅** | `I_out_L 限制在 ±Ki*65`                       | 积分项单步增量限幅，等价于 "误差超过 65 时积分不再增加"，防止过冲和饱和       |
| 输出限幅      | `pwm_L 限制在 ±10000`                         | 兜底保护（注意：实际给电机的最大占空比是 `PWM_MAX = 8000`，见 §3.4） |

> 注意代码里
> `I_out_L`
> 的限幅是
> `Ki*65`
> 而不是固定常数 65：即积分
>
> 项单步增量被限制为 Ki 的 65 倍。它的实际含义是 —— 当 | 误差 | > 65 时，积分增量封顶，避免在启动 / 急转弯时积分项无限累加导致大幅超调。

### 2.5 默认参数（调参的起点）




## 3. 反馈链路：编码器 + 二阶滞后滤波

PID 的 "实际速度" 来自编码器，每 2ms 采样一次。

### 3.1 电机控制主函数（2ms）



```
// Encoder.c —— Motor\\\_control()，在 cpu0\\\_main.c 主循环按 2ms 标志位调用

void Motor\\\_control(void)

{

\&#x20;   // 读编码器计数，二阶滞后滤波（注意负号：处理编码器/电机转向）

\&#x20;   encoder\\\_data\\\_1 = -SecondOrderLagFilter\\\_L(encoder\\\_get\\\_count(TIM6\\\_ENCODER)); // 左轮

\&#x20;   encoder\\\_data\\\_2 = -SecondOrderLagFilter\\\_R(encoder\\\_get\\\_count(TIM2\\\_ENCODER)); // 右轮

\&#x20;   // 读完后清零计数器（2ms 周期脉冲计数）

\&#x20;   encoder\\\_clear\\\_count(TIM2\\\_ENCODER);

\&#x20;   encoder\\\_clear\\\_count(TIM6\\\_ENCODER);

\&#x20;   // 脉冲数 → 速度（用于里程/距离积分）

\&#x20;   R\\\_speed = (((float)encoder\\\_data\\\_2/1024)\\\*0.4412\\\*0.2011)/0.002;

\&#x20;   L\\\_speed = (((float)encoder\\\_data\\\_1/1024)\\\*0.4412\\\*0.2011)/0.002;

\&#x20;   // ★ PID 计算：注意实际反馈值传入 2\\\*encoder\\\_data，与 ENCO\\\_Wish 同量纲

\&#x20;   pwm\\\_l = motorL\\\_pid(Motor\\\_Left\\\_PID, 2\\\*encoder\\\_data\\\_1, ENCO\\\_Wish\\\_L);

\&#x20;   pwm\\\_r = motorR\\\_pid(Motor\\\_Right\\\_PID, 2\\\*encoder\\\_data\\\_2, ENCO\\\_Wish\\\_R);

\&#x20;   set\\\_left\\\_speed(pwm\\\_l);

\&#x20;   set\\\_right\\\_speed(pwm\\\_r);

}
```

### 3.2 二阶滞后滤波（速度平滑，去编码器毛刺）



```
// FIliter.c —— 二阶滞后滤波

int16 SecondOrderLagFilter\\\_L(int16 value)

{

\&#x20;   static int16 last\\\_value, last\\\_2\\\_value;

\&#x20;   value = 0.2\\\*value + 0.4\\\*last\\\_value + 0.4\\\*last\\\_2\\\_value;  // 新值20% + 上次40% + 上上次40%

\&#x20;   last\\\_2\\\_value = last\\\_value;

\&#x20;   last\\\_value = value;

\&#x20;   return value;

}
```

> 滤波系数 0.2/0.4/0.4 是例程给的经验值：当前测量占 20%，历史占 80%。如果速度波形毛刺大，可以减小 0.2；如果响应太肉（滞后明显），可以增大 0.2。
> **滤波会引入滞后，滤波越重，P 能调得越大，但响应越慢 —— 这是一对 trade-off。**

### 3.3 量纲说明（重要）



* 编码器 2ms 计数一次，`motorL_pid` 的反馈传入的是 `2*encoder_data`；

* 因此**目标速度&#x20;**`ENCO_Wish_L/R`**&#x20;的单位是 "编码器 2ms 脉冲数的 2 倍"**，不是速度（m/s），也不是 PWM；

* 例程中 `ENCO_Wish_L = 100`（Encoder.c 初始值），`Basic_Speed = 145`，这些数值只有相对意义 ——**改编码器、改轮胎、改减速比后，这些数字要重新标定**。

### 3.4 PWM 输出与限幅



```
// control.c —— set\\\_left\\\_speed()：正转/反转分通道输出

\\#define PWM\\\_MAX 8000   // 实际允许的最大占空比

void set\\\_left\\\_speed(int16 speed\\\_pwm\\\_left){

\&#x20;   if(speed\\\_pwm\\\_left > PWM\\\_MAX)  speed\\\_pwm\\\_left =  PWM\\\_MAX;

\&#x20;   if(speed\\\_pwm\\\_left < -PWM\\\_MAX) speed\\\_pwm\\\_left = -PWM\\\_MAX;

\&#x20;   if(speed\\\_pwm\\\_left >= 0)  {          // 正转

\&#x20;       pwm\\\_set\\\_duty(ATOM0\\\_CH0\\\_P21\\\_2,  speed\\\_pwm\\\_left);

\&#x20;       pwm\\\_set\\\_duty(ATOM0\\\_CH1\\\_P21\\\_3,  0);

\&#x20;   } else {                            // 反转

\&#x20;       pwm\\\_set\\\_duty(ATOM0\\\_CH0\\\_P21\\\_2,  0);

\&#x20;       pwm\\\_set\\\_duty(ATOM0\\\_CH1\\\_P21\\\_3,  -speed\\\_pwm\\\_left);

\&#x20;   }

}

// set\\\_right\\\_speed 完全对称（ATOM0\\\_CH2/CH3）
```



* PWM 频率 10kHz（`pwm_init(ATOM0_CH0_P21_2,10000,0)`）；

* 电机驱动用 "两路 PWM 互补" 的方式控制正反转：正转给 CH0 占空比、CH1 给 0；反转反过来。

## 4. 目标速度从哪来：转向环（外环）

电机环只负责 "把实际速度追到 ENCO\_Wish"，**ENCO\_Wish 由转向环每 8ms 计算一次**。

### 4.1 转向环：模糊 PD → 差速目标



```
// pid.c —— turn\\\_pid()，在 8ms 中断里调用

void turn\\\_pid(){

\&#x20;   int error = 0;

\&#x20;   static int last\\\_error = 0;

\&#x20;   float Kp, Ki, Kd;

\&#x20;   double radian;

\&#x20;   error = ImageStatus.Det\\\_True;                 // 图像中线偏差（像素）

\&#x20;   turn.Kp = Fuzzy\\\_P(error, (error-last\\\_error)); // ★ 模糊推理得到 Kp

\&#x20;   turn.Kd = Fuzzy\\\_D(error, (error-last\\\_error)); // ★ 模糊推理得到 Kd

\&#x20;   Ki = turn.Ki; Kp = turn.Kp; Kd = turn.Kd;

\&#x20;   de = (error - last\\\_error);

\&#x20;   pid\\\_value = Kp\\\*error + Ki\\\*turn\\\_gyro\\\_x + Kd\\\*(error-last\\\_error);  // PD 输出

\&#x20;   last\\\_error = error;

\&#x20;   if(pid\\\_value > 0)   // 左转：左轮减速、右轮保持（差速转向）

\&#x20;   {

\&#x20;       radian = (pid\\\_value) \\\* 0.01;

\&#x20;       ENCO\\\_Wish\\\_L = (1 - radian\\\*xishu\\\_down) \\\* Basic\\\_Speed;  // 内侧轮减速（xishu\\\_down=0.9）

\&#x20;       ENCO\\\_Wish\\\_R = (1 + radian\\\*xishu\\\_up)   \\\* Basic\\\_Speed;  // 外侧轮加速（xishu\\\_up=0.15）

\&#x20;   }

\&#x20;   else                // 右转：右轮减速、左轮保持

\&#x20;   {

\&#x20;       radian = -(pid\\\_value) \\\* 0.01;

\&#x20;       ENCO\\\_Wish\\\_R = (1 - radian\\\*xishu\\\_down) \\\* Basic\\\_Speed;

\&#x20;       ENCO\\\_Wish\\\_L = (1 + radian\\\*xishu\\\_up)   \\\* Basic\\\_Speed;

\&#x20;   }

\&#x20;   difftry = radian;

\&#x20;   // 停车/出界/未启动时目标速度清零

\&#x20;   if(ImageFlag.chujie\\\_Stop\\\_1==1 || Motor\\\_Flag==0 || go==0){

\&#x20;       ENCO\\\_Wish\\\_L = 0; ENCO\\\_Wish\\\_R = 0;

\&#x20;   }

}
```

**差速系数含义：**



| 系数           | 值    | 作用                  |
| ------------ | ---- | ------------------- |
| `xishu_down` | 0.9  | 转弯时**内侧轮减速**比例（减得多） |
| `xishu_up`   | 0.15 | 转弯时**外侧轮加速**比例（加得少） |

> 代码注释里写："此处由前轮轮距和前后轮轴距决定，一般不需要改动"。这个系数本质是阿克曼差速的比例，跟车速没关系 ——
> **调电机 PID 时不要动它**
> 。

### 4.2 基础速度决策（弯道减速 / 直道加速）



```
// ProcessProperty.c —— Speed\\\_Decision()

void Speed\\\_Decision(void)

{

\&#x20;   if(ImageFlag.straight\\\_long == 1)   // 长直道

\&#x20;       Basic\\\_Speed = HSpeed;          // 高速（默认 150）

\&#x20;   else

\&#x20;       Basic\\\_Speed = LSpeed;          // 低速（默认 130）

}

// 各元素还有独立的基准速度：直道 300、弯道 230、坡道 200、环岛 235\\\~260 等

// 见 Element\\\_Data\\\_Init()，不同拨码档位取不同速度
```

**小结：外环（8ms）根据图像偏差算出左右轮目标速度 ENCO\_Wish；内环（2ms）用增量式 PI 让实际编码器速度追上目标。调参时先保证内环能跟上，再谈外环。**

## 5. 调参思路详解（例程是怎么调的）

### 5.1 调参总路线



```
第0步 确认反馈正确（编码器方向、滤波、量纲）

第1步 只调 P：Ki=0，直道跑，Kp 从 0 往上加，直到"跟得上且不明显震荡"

第2步 加 I：Ki 从 0 往上加，消除稳态误差（速度环一般 Ki 很小）

第3步 检查限幅：I 限幅 Ki\\\*65、输出限幅 PWM\\\_MAX 是否合理

第4步 左右轮分别调（用 EL/ER 单独给定目标速度）

第5步 合起来跑赛道，微调；再调外环（模糊 PD 基准 fuzzy\\\_p/fuzzy\\\_d）
```

### 5.2 准备工作



1. **接线**：UART2（P10\_5=TX、P10\_6=RX），波特率 115200，接 USB-TTL 或逐飞无线串口；

2. **上位机**：VOFA+（JustFloat 或 FireWater 协议）或任意串口助手；

3. **参数复位**：先烧录原始程序（`PID_Init` 里的初值），确认 `go` 启动逻辑、`Motor_Flag` 打开；

4. **确认反馈正确**：串口打印 `encoder_data_1 / encoder_data_2`，推车时数值应随轮子转动而变，正负方向要和 `ENCO_Wish` 符号一致（例程用负号 `-SecondOrderLagFilter_L(...)` 就是为了统一方向）。

### 5.3 第一步：只调 P（Ki=0）



* 用上位机发 `I1=0!`、`I2=0!` 把积分清零；

* 发 `EL=100!`、`ER=100!` 给定一个固定的目标速度（或直接在代码里把 `ENCO_Wish` 设成固定值，车放直道上跑）；

* 从 `P1=10!`、`P2=10!` 开始，逐步加大（例程最终参考值 70），观察：


  * **Kp 太小**：实际速度迟迟追不上目标，误差大、加速慢（响应肉）；

  * **Kp 合适**：速度快速跟上目标，无超调或轻微超调，电机声音平稳；

  * **Kp 太大**：速度在目标附近来回震荡，电机有 "嗡嗡" 声、车身抖动。

* 例程参考起点：`Kp=70`（对应 2ms 周期、编码器 2 倍量纲），但**换车架 / 换电池 / 换编码器后必须重调**。

### 5.4 第二步：加 I 消除静差



* P 调好后，实际速度会和目标差一个固定值（静差，尤其上坡 / 带载时），此时加 I；

* 从 `I1=0.5!`、`I2=0.5!` 起步逐步加到例程参考值 `3.5`；

* **观察**：I 太小→静差消不掉；I 合适→实际速度稳定贴合目标；I 太大→速度来回摆动（低频振荡），此时减小 I；

* 增量式 PI 中 I 项本身有 "单步增量限幅"（`±Ki*65`），所以一般不会像位置式那样积分饱和，但如果 I 加过头仍会振荡。

### 5.5 第三步：限幅的作用



* **I 项限幅&#x20;**`Ki*65`：防止启动 / 急加速时积分项冲过头。如果起步大超调，可把 65 改小（比如 40）；

* **输出限幅**：PID 内部 `±10000`，实际输出 `±PWM_MAX(8000)`。如果发现速度环在高速时 "给满油也追不上"，先确认是不是 PWM\_MAX 不够，而不是盲目加 Kp；

* **不要轻易加大 P 来解决 "追不上"**：追不上通常是 PWM 饱和或目标速度定太高，不是 P 小。

### 5.6 在线调参协议（例程自带，VOFA+/ 串口助手直接发）

例程在 `code/pid_adjust.c` 里写好了串口在线调参，CPU0 的 UART2 接收中断收到 `!` 结尾的一帧后自动解析生效：



| 要改的参数   | 发送指令              | 说明                     |
| ------- | ----------------- | ---------------------- |
| 左轮 Kp   | `P1=70!`          | 设 `Motor_Left_PID.Kp`  |
| 左轮 Ki   | `I1=3.5!`         | 设 `Motor_Left_PID.Ki`  |

### 5.7 转向环模糊 PID 的调法（内环调好后再调）

转向环的 Kp/Kd 不是固定值，而是由模糊推理表（`FUZZYPID.c`）根据偏差 E 和偏差变化率 EC 动态给出，你只需要调两个基准值：



```
// FUZZYPID.c —— 模糊输出以 fuzzy\\\_p / fuzzy\\\_d 为基准

// P 输出：UFF\\\[7] = {fuzzy\\\_p-0.4, fuzzy\\\_p-0.2, fuzzy\\\_p, fuzzy\\\_p+0.2, fuzzy\\\_p+0.4, fuzzy\\\_p+0.6, fuzzy\\\_p+0.8}

// D 输出：UFF\\\[7] = {fuzzy\\\_d-4, fuzzy\\\_d-2, fuzzy\\\_d, fuzzy\\\_d+2, fuzzy\\\_d+5, fuzzy\\\_d+8, fuzzy\\\_d+10}
```

调法：



1. 先把 `fuzzy_p` 从小到大试：太小→过弯打角不足、切弯；太大→弯道内抖动、甩尾；

2. `fuzzy_d` 负责抑制动态超调：弯道出口摆尾就加 D；

3. 例程还按 `PWM_MAX` 分档给了三组基准（cpu0\_main.c）：



```
if(PWM\\\_MAX==8000){ fuzzy\\\_p=4.385; fuzzy\\\_d=14.350; }

else if(PWM\\\_MAX==9000){ fuzzy\\\_p=5.580; fuzzy\\\_d=16.250; }

else if(PWM\\\_MAX==9999){ fuzzy\\\_p=4.380; fuzzy\\\_d=14.251; }
```

**车速档位变了，模糊基准要跟着变 —— 这就是例程 "速度分档配参数" 的思路。**

## 7. 调参避坑清单



1. **先确认编码器方向和量纲**再调参 —— 方向反了，P 越大越飞车；

2. **I 从 0 开始**，不要照抄 3.5—— 不同车架 / 电池 / 电机，I 差别很大；

3. **调内环时固定外环**：把车架空或放直道、固定 ENCO\_Wish，只看速度环；

4. **追不上 ≠ P 小**：先查 PWM\_MAX 是否饱和（打印 pwm\_l/pwm\_r 看是否顶到 8000）；

5. **左右轮分开调**（用 EL/ER 单独给定），两边机械差异会造成跑偏；

6. **滤波系数影响 P 上限**：滤波越重波形越平但滞后越大，P 可以大一些，但响应慢 —— 按实际手感平衡；

7. **改完参数要固化**：在线调参只是临时生效，掉电丢失；调好后写回 `PID_Init()` 并重新烧录；

8. **速度环（内环）是地基**：内环不跟手，外环调得再好车也是 "忽快忽慢"，先内环后外环，不要跳步。
