## 0. 整体调用链（先看数据从哪来到哪去）



```
turn\_callback()  —— 10ms 定时器中断回调（main.cpp）

&#x20;  │

&#x20;  ├─ 绕行 YAW 相位：bias = (g\_detour\_debug\_target\_yaw - g\_detour\_yaw\_angle) × YAW\_BIAS\_GAIN

&#x20;  └─ 正常循迹 TRACK：bias = image\_bias（视觉偏差，±20）

&#x20;  │

&#x20;  ▼

MotorDriver\_TurnControlNew(bias)          —— driver/Motor.cpp

&#x20;  ├─ Kp = Fuzzy\_P(E, EC, 基础Kp)         —— FuzzyPID.cpp  ★ 动态调参

&#x20;  ├─ Kd = Fuzzy\_D(E, EC, 基础Kd)         —— FuzzyPID.cpp  ★ 动态调参

&#x20;  ├─ pid\_val = (Kp·E + Kd·EC) / 20       —— PD 输出归一化

&#x20;  └─ 左右轮目标速度 encoder\_L/R\_wish     —— 差速分配（内轮减0.95 / 外轮加0.10）

&#x20;  │

&#x20;  ▼

速度环 2ms（增量式 PI）→ PWM → 电机 → 编码器反馈
```

**分工**：转向环（外环，10ms）只负责算 "左右轮目标速度差"；速度环（内环，2ms）负责把实际速度追到目标。模糊 PID 发生在**转向环内部**，作用在 Kp/Kd 上。

## 1. 为什么需要模糊 PID（动机）

转向环如果只用固定 Kp/Kd，会遇到一对矛盾：



| 工况   | 偏差特征     | 固定大 Kp 的问题       | 固定小 Kp 的问题        |
| ---- | -------- | ---------------- | ----------------- |
| 直道   | E≈0，微小抖动 | 增益高 → 抖动被放大 → 画龙 | 无所谓               |
| 急弯   | E 大且快速增大 | 合适（响应快）          | 增益低 → 切弯不足 → 冲出赛道 |
| 弯道出口 | E 大但正在收敛 | 容易过冲回摆           | 合适                |

**结论**：Kp/Kd 必须**随工况变**。模糊 PID 的方案是：



1. 提取两个 "工况特征量"—— 偏差 **E**、偏差变化率 **EC**（= E - 上一帧 E，反映偏差在变大还是变小）；

2. 用 7×7 模糊规则表查 "该用多大的增益"；

3. 把基础参数 `turn_pid_new.Kp/Kd` **乘上一个系数**输出。

**关键设计：相对调度而不是绝对调度**——2026 的模糊输出是 "基础值 × 系数（0.85\~1.35）"。好处是：改基础 Kp/Kd 不用重调模糊表，模糊表只负责 "相对缩放"。

## 2. 转向环实现：`MotorDriver_TurnControlNew`（逐行）



```
// driver/Motor.cpp

// 基础参数（全局）：turn\_pid\_new = {Kp=1.52, Ki=0, Kd=10.4}   ← Ki 恒为 0，纯 PD

void MotorDriver\_TurnControlNew(float bias)

{

&#x20;   static float last\_error = 0.0f;              // 上一帧偏差（static，跨帧保持）

&#x20;   float error = bias;                          // ① 偏差来源：image\_bias 或 YAW 角度误差

&#x20;   float Kp = turn\_pid\_new.Kp;                  // ② 取出基础增益

&#x20;   float Kd = turn\_pid\_new.Kd;

&#x20;   // ③ ★ 模糊增益调度：按 (error, Δerror) 动态缩放 Kp/Kd

&#x20;   Kp = Fuzzy\_P(error, (error - last\_error), Kp);   // 返回 = 基础Kp × 系数(0.90\~1.30)

&#x20;   Kd = Fuzzy\_D(error, (error - last\_error), Kd);   // 返回 = 基础Kd × 系数(0.85\~1.35)

&#x20;   fuzzyp = Kp;                               // ④ 调试用全局量（示波器可看）

&#x20;   fuzzyd = Kd;

&#x20;   ec = error - last\_error;

&#x20;   ec = Limit(ec, -3.0f, 3.0f);               // ⑤ EC 限幅 ±3（防止偏差跳变时 D 项炸掉）

&#x20;   // ⑥ PD 输出归一化：/20 把 Kp·E + Kd·EC 缩到"差速比例"量级

&#x20;   //    （E∈±20，Kp≈1.5\~2，Kd≈9\~14，EC∈±3 → pid\_val 约 ±4 以内）

&#x20;   float pid\_val = (Kp \* error + Kd \* ec) / 20.0f;

&#x20;   last\_error = error;

&#x20;   // ⑦ 差速分配：pid\_val>0 需左转，<0 需右转

&#x20;   if (pid\_val > 0.0f) {                      // 左转：内轮(左)大减速，外轮(右)小加速

&#x20;       encoder\_left\_wish  = (int16\_t)((1.0f - pid\_val \* 0.95f) \* base\_speed);

&#x20;       encoder\_right\_wish = (int16\_t)((1.0f + pid\_val \* 0.10f) \* base\_speed);

&#x20;       if (encoder\_left\_wish < 0) encoder\_left\_wish = 0;   // 内轮钳到 ≥0，防止反转打转

&#x20;   } else {                                   // 右转：对称

&#x20;       float radian = -pid\_val;

&#x20;       encoder\_right\_wish = (int16\_t)((1.0f - radian \* 0.95f) \* base\_speed);

&#x20;       encoder\_left\_wish  = (int16\_t)((1.0f + radian \* 0.10f) \* base\_speed);

&#x20;       if (encoder\_right\_wish < 0) encoder\_right\_wish = 0;

&#x20;   }

}
```

### 2.1 三个关键设计点的含义



1. `/20`**&#x20;归一化**：`image_bias` 的量纲是 "归一化转角"（±20），而差速比例要落在 ± 几的量级。直接 `(Kp·E+Kd·EC)/20` 后，`pid_val≈0.1~4`，再乘 0.95/0.10 就是差速比例。**改偏差量纲（比如视觉队友改成 ±10）时，这个 20 必须跟着改**。

2. **内轮减 0.95 / 外轮加 0.10（不对称差速）**：转弯以**减速为主、加速为辅**—— 内侧轮大幅减速（甚至钳到 0 原地转），外侧轮只小幅加速。这样既保出弯速度又不容易甩尾。和 2025 例程的 `xishu_down=0.9 / xishu_up=0.15` 是同一个思路，2026 把内侧减得更狠。

3. **内轮钳到 ≥0**：大偏差时 `pid_val` 可能 >1，`(1 - 1×0.95)×base_speed` 会变负。如果不钳，内轮反转会导致车辆原地打转、车身姿态乱。只有绕行 YAW 阶段（`g_yaw_active=1`）才允许内轮反转做原地转向。

### 2.2 偏差来源切换（方案 D）

`main.cpp` 的 `turn_callback` 决定喂什么偏差：



```
void turn\_callback() {

&#x20;   if (g\_detour\_yaw\_phase) {                  // 绕行 YAW 相位：用 IMU 角度误差

&#x20;       float yaw\_error = g\_detour\_debug\_target\_yaw - g\_detour\_yaw\_angle;

&#x20;       while (yaw\_error > 180.0f)  yaw\_error -= 360.0f;   // 角度差归一到 ±180°

&#x20;       while (yaw\_error < -180.0f) yaw\_error += 360.0f;

&#x20;       MotorDriver\_TurnControlNew(yaw\_error \* YAW\_BIAS\_GAIN);   // YAW\_BIAS\_GAIN=1.0

&#x20;   } else {

&#x20;       MotorDriver\_TurnControlNew(image\_bias);     // 正常循迹：视觉偏差

&#x20;   }

&#x20;   ...

}
```

也就是说**转向环本身不用改**，换偏差来源即可 —— 这是 2026 把 "循迹" 和 "绕行转向" 统一到同一个控制器的做法。

## 3. 模糊 PID 详解（FuzzyPID.cpp）

### 3.1 接口



```
float Fuzzy\_P(float E, float EC, float Steer\_P);   // 返回调制后的 P（基础值×0.90\~1.30）

float Fuzzy\_D(float E, float EC, float Steer\_D);   // 返回调制后的 D（基础值×0.85\~1.35）
```



* `E`：偏差（= image\_bias），内部限幅 ±16；

* `EC`：偏差变化量（= 上一帧偏差差），内部限幅 ±6；

* 第三个参数是**基础值**（`turn_pid_new.Kp/Kd`），模糊只负责乘系数。

### 3.2 论域（非线性设计）



```
// E 论域边界：零点密集、边缘稀疏 —— 匹配 tanθ 特性

static const float E\_BOUNDARIES\[7] = {-16.0f, -8.0f, -3.0f, 0.0f, 3.0f, 8.0f, 16.0f};

// EC 论域边界：±1.2 内密集，提升直道稳态分辨率

static const float EC\_BOUNDARIES\[7] = {-6.0f, -2.0f, -1.2f, 0.0f, 1.2f, 2.0f, 6.0f};
```

**7 个边界把论域切成 6 段**，对应 7 个模糊语言值：**NB (负大)、NM (负中)、NS (负小)、ZO (零)、PS (正小)、PM (正中)、PB (正大)**。

非线性布点的原因（代码注释原话）：圆环段偏差集中在 ±8 附近，把 PS/PM 分界从 7 拉到 8，减少圆环稳态时的等级跳变（"六边形效应" 根因）；EC 原来 ±5 不够，急弯出入弯实测可达 6\~8，所以扩到 ±6。

**索引计算是 O (1) 的 if-else 链**（最坏 3 次比较，无循环，LoongArch/TC264 都友好）：



```
static inline fuzzy\_idx\_t E\_To\_Index(float E) {

&#x20;   if (E <= -16.0f) return 0;   // NB

&#x20;   if (E <=  -8.0f) return 1;   // NM

&#x20;   if (E <=  -3.0f) return 2;   // NS

&#x20;   if (E <=   3.0f) return 3;   // ZO   ← 注意：-3\~+3 都是 ZO

&#x20;   if (E <=   8.0f) return 4;   // PS

&#x20;   if (E <=  16.0f) return 5;   // PM

&#x20;   return 6;                    // PB

}

// EC\_To\_Index 同理，边界为 ±6 / ±2 / ±1.2 / 0
```

### 3.3 规则表（模糊知识的核心）

**P 规则表 RULE\_P**（行 = E，列 = EC，值为 0\~6，即 PCT 系数下标）：



```
&#x20;     EC:  NB   NM   NS   ZO   PS   PM   PB

E: NB     6    5    4    3    2    1    0

&#x20;  NM     5    4    3    2    1    0    1

&#x20;  NS     4    3    2    1    0    1    2

&#x20;  ZO     3    2    1    0    1    2    3

&#x20;  PS     2    1    0    1    2    3    4

&#x20;  PM     1    0    1    2    3    4    5

&#x20;  PB     0    1    2    3    4    5    6
```

**语义**：



* **主对角线（NB,NB）和（PB,PB）= 6 → P 放大到 1.30**：偏差大且还在同向增大（入弯），需要强响应；

* **副对角线（NB,PB）和（PB,NB）= 0 → P 缩到 0.90**：偏差大但正在反向收敛（出弯回正），压低 P 防超调；

* **中心（ZO,ZO）= 0**：直道稳态，P 缩到 0.90（配合插值约 0.90~0.95），避免过度修正。

**D 规则表 RULE\_D**：



```
&#x20;     EC:  NB   NM   NS   ZO   PS   PM   PB

E: NB     0    1    2    3    4    5    6

&#x20;  NM     1    2    3    4    5    6    5

&#x20;  NS     2    3    4    5    6    5    4

&#x20;  ZO     3    4    5    6    5    4    3

&#x20;  PS     4    5    6    5    4    3    2

&#x20;  PM     5    6    5    4    3    2    1

&#x20;  PB     6    5    4    3    2    1    0
```

**语义（和 P 正好互补）**：



* **中心（ZO,ZO）= 6 → D 最大（×1.35）**：直道 D 最大，阻尼最足，压住高频抖动；

* **（NB,NB）和（PB,PB）= 0 → D 最小（×0.85）**：急弯入弯放开阻尼，允许快速打角；

* **（NB,PB）和（PB,NB）= 6 → D 最大**：出弯回正时增强阻尼，防回摆甩尾。

一句话记法：**P 在 "要用力" 时放大（入弯），D 在 "要稳住" 时放大（直道 / 出弯）**。

### 3.4 模糊推理核心：`Fuzzy_Adjust`（逐行）



```
static float Fuzzy\_Adjust(float E, float EC, float base,

&#x20;                         const int8\_t rule\[7]\[7], const float uff\_pct\[7])

{

&#x20;   // ① 输入限幅

&#x20;   E  = CLAMP(E,  -16.0f, 16.0f);

&#x20;   EC = CLAMP(EC, -6.0f, 6.0f);

&#x20;   // ② O(1) 索引：E、EC 各自落到哪个语言值区间

&#x20;   fuzzy\_idx\_t e\_idx  = E\_To\_Index(E);

&#x20;   fuzzy\_idx\_t ec\_idx = EC\_To\_Index(EC);

&#x20;   // ③ 激活 4 条规则：取 (e\_idx, e\_idx+1) × (ec\_idx, ec\_idx+1) 四个角上的规则值

&#x20;   //    边界处重复自身（e\_idx=6 或 ec\_idx=6 时）

&#x20;   int8\_t Un\[4];

&#x20;   Un\[0] = rule\[e\_idx]\[ec\_idx];               // 左下

&#x20;   Un\[1] = rule\[e\_idx + 1]\[ec\_idx];           // 右下（边界时=e\_idx）

&#x20;   Un\[2] = rule\[e\_idx]\[ec\_idx + 1];           // 左上

&#x20;   Un\[3] = rule\[e\_idx + 1]\[ec\_idx + 1];       // 右上

&#x20;   // ④ 隶属度：当前 E 在区间内的线性插值（三角隶属函数）

&#x20;   float mu\_e\[2], mu\_ec\[2];

&#x20;   mu\_e\[0] = (e\_hi - E) / (e\_hi - e\_lo);      // 属于"低边界"的程度

&#x20;   mu\_e\[1] = 1.0f - mu\_e\[0];                  // 属于"高边界"的程度

&#x20;   // EC 同理

&#x20;   // ⑤ 取小运算（AND）：激活强度 = min(μe, μec)

&#x20;   float UF\[4];

&#x20;   UF\[0] = MIN(mu\_e\[0], mu\_ec\[0]);

&#x20;   UF\[1] = MIN(mu\_e\[1], mu\_ec\[0]);

&#x20;   UF\[2] = MIN(mu\_e\[0], mu\_ec\[1]);

&#x20;   UF\[3] = MIN(mu\_e\[1], mu\_ec\[1]);

&#x20;   // ⑥ 加权平均解模糊（只累加激活强度>0 的规则）

&#x20;   float weighted\_sum = 0, sum\_weights = 0;

&#x20;   for (int i = 0; i < 4; i++) {

&#x20;       if (UF\[i] > 0.0f) {

&#x20;           float output = base \* uff\_pct\[Un\[i]];   // 规则值 → 系数下标 → 系数 × 基础值

&#x20;           weighted\_sum += UF\[i] \* output;

&#x20;           sum\_weights  += UF\[i];

&#x20;       }

&#x20;   }

&#x20;   return (sum\_weights > 0.0f) ? (weighted\_sum / sum\_weights) : base;

}
```

**为什么是这五步**：



1. **限幅**：防止 E/EC 超出论域时索引越界；

2. **索引**：把连续量离散成语言值（O (1)，实时性好）；

3. **4 规则激活**：任何一个输入点都只落在两个相邻语言值之间，所以最多 4 条规则参与（标准 Mamdani 模糊推理的 "相邻规则激活" 性质）；

4. **三角隶属度**：`μ = (边界 - 输入)/(边界差)`，离哪个边界近就属于谁；

5. **取小 = AND**：规则 "如果 E 是 A 且 EC 是 B" 的激活强度取两个隶属度的小者；

6. **加权平均**：4 条规则的输出系数按激活强度加权平均，得到平滑连续的增益 ——**这就是 "动态调整" 的数学本质：增益是 E、EC 的连续函数，而不是档位跳变**。

### 3.6 手算示例（三组典型工况，验证 "动态" 效果）

设基础 `turn_pid_new = {Kp=1.52, Kd=10.4}`：



| 工况        | E  | EC | 索引 (e,ec) | 激活规则值→系数                | P 系数     | D 系数     | 效果         |
| --------- | -- | -- | --------- | ----------------------- | -------- | -------- | ---------- |
| 直道稳态      | 0  | 0  | (ZO,ZO)   | P:{0,1,1,2} D:{6,5,5,4} | **0.90** | **1.35** | 小 P 大 D：稳  |
| 中等偏差 + 增大 | 6  | 2  | (PS,PS)   | P:{2,3,3,4} D:{4,3,3,2} | **1.07** | **1.00** | P 增、D 平    |
| 急弯入弯      | 14 | 5  | (PM,PM)   | P:{4,5,5,6} D:{2,1,1,0} | **1.23** | **0.90** | 大 P 小 D：敢打 |

**手算验证（急弯入弯 E=14, EC=5）**：



1. `E_To_Index(14)=5(PM)`，区间 \[8,16]，`μe0=(16-14)/8=0.25`，`μe1=0.75`；

2. `EC_To_Index(5)=5(PM)`，区间 \[2,6]，`μec0=(6-5)/4=0.25`，`μec1=0.75`；

3. 激活：`P:{4,5,5,6}`、`D:{2,1,1,0}`（查表）；激活强度 `UF={0.25,0.25,0.25,0.75}`；

4. P 输出 = `(0.25×1.10 + 0.25×1.20 + 0.25×1.20 + 0.75×1.30)/1.5 = 1.233` → **Kp ≈ 1.52×1.23 ≈ 1.87**；

5. D 输出 = `(0.25×0.98 + 0.25×0.92 + 0.25×0.92 + 0.75×0.85)/1.5 = 0.895` → **Kd ≈ 10.4×0.90 ≈ 9.31**。

→ 入弯瞬间 Kp 拉到接近上限、Kd 压到接近下限，车 "敢打方向"；回直道后 Kp 缩回 0.90、Kd 拉到 1.35，车 "稳得住"。这就是模糊 PID 的全部作用。

## 4. 动态调整参数逻辑（再总结一遍）

把第 3 节串起来，动态调参的完整逻辑链：



```
每10ms（turn\_callback）

&#x20; E   = image\_bias / YAW误差        （偏差）

&#x20; EC  = E - last\_error              （偏差变化率）

&#x20;       │

&#x20;       ▼

&#x20; Fuzzy\_P / Fuzzy\_D

&#x20;   ① 限幅 E±16、EC±6

&#x20;   ② E→索引(0\~6)，EC→索引(0\~6)      （O(1) 查表）

&#x20;   ③ 查 RULE\_P / RULE\_D 得 4 个规则值  （0\~6）

&#x20;   ④ 三角隶属度 μe、μec             （线性插值）

&#x20;   ⑤ 取小 → 激活强度 UF\[4]

&#x20;   ⑥ 加权平均 → 输出系数 c           （0.85\~1.35 连续值）

&#x20;       │

&#x20;       ▼

&#x20; Kp = turn\_pid\_new.Kp × cP        （基础值 × 系数）

&#x20; Kd = turn\_pid\_new.Kd × cD

&#x20; pid\_val = (Kp·E + Kd·EC)/20      （PD 归一化）

&#x20; encoder\_L/R\_wish = base\_speed × (1 ∓ 0.95·pid\_val, 1 ± 0.10·pid\_val)
```

**"动态" 的本质**：增益是 (E, EC) 的**连续二维函数**—— 同一个 E 配不同的 EC 会得到不同的增益；E、EC 连续变化时，加权平均让增益平滑过渡，不会档位跳变（这正是 2025 例程里被注释掉的 "`Kp += KP2·error²` 非线性增益 " 方案的升级版：模糊更平滑、更可控）。

### 4.1 USE\_CAR\_108 变体

`Typedef.hpp` 的 `USE_CAR_108` 宏切换另一套 PCT（108 开发板整车验证版）：P 系 `{0.90,0.94,0.98,1.0,1.08,1.16,1.24}`、D 系 `{0.84,0.89,0.94,1.0,1.06,1.13,1.20}`—— 近零区压得更低（防出弯回直抖动）、大弯抬得更高（连续急弯第二弯响应）。**换车架 / 换速度档时，优先调这套系数，不要动规则表**。

### 4.2 与 TC264（2025 例程）的差异 → 落地建议



| 维度     | 2025 TC264 例程                                                         | 2026 龙芯工程                               | 建议                                     |
| ------ | --------------------------------------------------------------------- | --------------------------------------- | -------------------------------------- |
| 模糊输出   | **绝对值**：`UFF[7]={fuzzy_p-0.4, -0.2, fuzzy_p, +0.2, +0.4, +0.6, +0.8}` | **相对值**：基础值 × 系数                        | **建议改成相对值**，换基础 Kp 不用重调模糊表             |
| 基准参数   | `fuzzy_p=4.385 / fuzzy_d=14.350`（直接是 Kp/Kd 本体）                        | `turn_pid_new={1.52,0,10.4}`（基础值，模糊只缩放） | 相对值思路：`turn.Kp=1.35 / turn.Kd=9.33` 起步 |
| PD 归一化 | `pid_value = Kp·e + Ki·gyro + Kd·(e-last)`，差速乘 0.01                   | `pid_val = (Kp·e + Kd·ec)/20`           | 按你的 `image_bias` 量纲定除数                 |
| EC 处理  | 未限幅                                                                   | 模糊内部 ±6，D 项另限 ±3                        | 建议照抄限幅，防偏差跳变                           |

TC264 移植模板（直接可用）：



```
// TC264 版转向环（8ms），模糊输出改为"基础值×系数"

float Fuzzy\_P\_tc(float E, float EC, float base\_p) { ... 同 2026 五步 ... return 系数×base\_p; }

float Fuzzy\_D\_tc(float E, float EC, float base\_d) { ... }

void turn\_pid(void)

{

&#x20;   static int16 last\_error = 0;

&#x20;   int16 E  = image\_bias;                     // 视觉偏差（±20）

&#x20;   int16 EC = E - last\_error;

&#x20;   if (EC > 3)  EC = 3;  if (EC < -3) EC = -3;

&#x20;   float Kp = Fuzzy\_P\_tc(E, EC, turn.Kp);     // turn.Kp=1.35 起步

&#x20;   float Kd = Fuzzy\_D\_tc(E, EC, turn.Kd);     // turn.Kd=9.33 起步

&#x20;   float pid\_val = (Kp \* E + Kd \* EC) / 20.0f;

&#x20;   if (pid\_val > 0) {

&#x20;       ENCO\_Wish\_L = (int16)((1.0f - pid\_val \* 0.95f) \* Basic\_Speed);

&#x20;       ENCO\_Wish\_R = (int16)((1.0f + pid\_val \* 0.10f) \* Basic\_Speed);

&#x20;       if (ENCO\_Wish\_L < 0) ENCO\_Wish\_L = 0;

&#x20;   } else {

&#x20;       float r = -pid\_val;

&#x20;       ENCO\_Wish\_R = (int16)((1.0f - r \* 0.95f) \* Basic\_Speed);

&#x20;       ENCO\_Wish\_L = (int16)((1.0f + r \* 0.10f) \* Basic\_Speed);

&#x20;       if (ENCO\_Wish\_R < 0) ENCO\_Wish\_R = 0;

&#x20;   }

&#x20;   last\_error = E;

}
```

## 5. 怎么调（参数 → 现象 → 动作）



| 现象         | 原因            | 动作                                                    |
| ---------- | ------------- | ----------------------------------------------------- |
| 直道画龙 / 抖动  | Kp 过大（或 D 不足） | 降基础 `Kp`，或抬 PCT 近零区系数（0.90→0.85），或抬 D 近零区             |
| 弯道切角不足、冲出去 | 入弯增益不够        | 抬基础 `Kp`，或抬 PCT 高档系数（1.30→1.35）                       |
| 弯道内抖动 / 甩尾 | D 不足          | 抬基础 `Kd`                                              |
| 出弯回直后左右摆   | 出弯阻尼不够 / P 过大 | 抬 D 高档（1.35），压 P 副对角线档（0.90）                          |
| 连续急弯第二弯没反应 | 入弯 D 压太狠      | 抬 D 低档（0.85→0.90），或抬 P 高档                             |
| 高速时整体发散    | 速度档变了增益没变     | 按速度分档配 PCT（2025 例程的思路：PWM\_MAX 分档配 fuzzy\_p/fuzzy\_d） |

**调参铁律**（和《霹雳火 2025 电机 PID 调参参考》一致）：



1. **单变量**：一次只改一个参数，跑一圈看数据；

2. **先内环后外环**：速度环不跟手，转向环调得再好也白搭；

3. **用波形说话**：逐飞助手 8 通道或 VOFA+ 看 `fuzzyp/fuzzyd/pid_val/左右轮目标vs实际`；

4. **模糊表先别动**：优先调基础 `turn_pid_new.Kp/Kd` 和 PCT 系数，规则表（RULE\_P/RULE\_D）是结构性的，一般不动；

5. **EC 论域分析**：2026 工程 `Typedef.hpp` 里 `EC_LOG_ENABLE=1` 会把 EC 记录到 `./ec_data.txt`，如果发现 EC 长期顶在 ±6，说明论域要扩。

## 7. 常见误解清单



1. **"模糊 PID 是第三个 PID 环"** —— 不是，它只改转向环的 Kp/Kd，环的结构没变；

2. **"规则表越大越好"** —— 不是，7×7 是精度 / 实时性 / 可调性的平衡点，规则表是结构性知识，轻易不改；

3. **"改模糊表能解决所有问题"** —— 不是，先确认速度环跟上、基础 Kp/Kd 量级对，再谈模糊；

4. **"系数越大越好"** —— 不是，直道系数 0.90 是有意的 "欠增益"，防抖动；系数上限 1.30 是有意的 "防过冲"；

5. **"EC 可以不管"** —— 不是，EC 是模糊的第二维输入，入弯 / 出弯的区分全靠它；EC 符号接反（比如 image\_bias 方向反了），P 会在入弯时反而缩小，表现就是 "弯道越打越没反应"——**image\_bias 符号正确性是一切的前提**。
