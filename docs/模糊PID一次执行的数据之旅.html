一次转向环执行的数据之旅（示意）
以 E=6、EC=2 为例，跟着数字从偏差一路走到左右轮差速目标。蓝色=P 支路，橙色=D 支路。
① 输入（每 10ms 一次）
image_bias = 6（假设上一帧 = 4）
EC = 6 − 4 = 2
② 限幅
E=6（≤16 不变）
EC=2（≤6 不变）
超出论域才被卡住
③ 档位编号（O(1) 查表）
E_To_Index(6) = 4（PS）
EC_To_Index(2) = 4（PS）
④ 激活 4 条相邻规则（查规则表）
P 支路：Un = {2, 3, 3, 4}（系数下标）
D 支路：Un = {4, 3, 3, 2}（系数下标）
⑤ 隶属度（线性插值）
E=6 在 [3,8]：μ_PS = (8−6)/5 = 0.4，μ_PM = 0.6
EC=2 恰在锚点：μ_PS = 0，μ_PM = 1.0
⑥ 取小 AND → 激活强度
UF = {min(0.4,0), min(0.6,0), min(0.4,1), min(0.6,1)}
= {0, 0, 0.4, 0.6}
EC 只属于 PM → 插值完全由 E 提供
⑦ 加权平均 → 增益系数
P 系数 = (0.4×1.03 + 0.6×1.10)/1.0 = 1.07
D 系数 = (0.4×1.03 + 0.6×0.98)/1.0 = 1.00
⑧ 基础值 × 系数 → Kp/Kd
Kp = 1.52 × 1.07 = 1.63
Kd = 10.4 × 1.00 = 10.4
⑨ PD 合成 → 转向强度
ec = Limit(2, ±3) = 2
Kp·E = 1.63×6 = 9.76，Kd·EC = 10.4×2 = 20.8
pid_val = (9.76 + 20.8) / 20 = 1.53（>0 → 左转）
⑩ 差速分配（pid_val=1.53 > 0 → 左转分支）
左轮 = (1 − 1.53×0.95) × B = −0.45B → 钳到 0
右轮 = (1 + 1.53×0.10) × B = 1.15B（提速 15%）
⑪ 交给速度环（2ms）：左轮目标 0，右轮目标 1.15B
左轮停转、右轮加速 → 车头急往左拐。偏差越大 pid_val 越大 → 转弯越狠，这套逻辑自动完成"偏差越大打得越猛"。
数值按 FuzzyPID.cpp 与 Motor.cpp 的实际公式手算复现（基础 Kp=1.52 / Kd=10.4）。示意结构，示例数据标注明确。
